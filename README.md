# python-start

Учебные проекты на Python. Первые шаги: переменные, условия, циклы,
списки и словари.

## Проекты

- `info.py` — знакомство с переменными и вводом
- `quiz.py` — викторина: условия, циклы, структуры данных
- `lists.py` — задачи на списки
- `shop.py` — расчёт стоимости товаров: список словарей
- `make_data.py` — генератор продаж магазина в формате csv
- `analysis.py` — анализ продаж магазина

## analysis.py — анализ продаж

Программа читает `orders.csv` (200 заказов) и считает выручку,
скидки, разбивку по категориям, товарам и дням недели.

### Выводы

- Влияние скидок: скидки уменьшили выручку на 7,1%, что в абсолютном выражении составляет 162 754 руб. за анализируемый период.
- Лидер по выручке: комнатные растения обеспечивают 64,5% выручки, хотя на них приходится лишь 30% заказов. Это объясняется более высокой средней ценой — 958 руб. против 178 руб. у срезанных цветов.
- Аутсайдер: срезанные цветы демонстрируют наихудший результат, формируя только 12,8% выручки.
- Разбивка по дням недели: поскольку make_data.py генерирует данные случайным образом, распределение по дням недели не содержит устойчивых закономерностей и представляет собой шум.

## Как запустить

```bash
python quiz.py
```

Нужен Python 3.10 или новее.

# python-start

Учебные проекты на Python. Первые шаги: переменные, условия, циклы,
списки и словари.

## Проекты

- `info.py` — знакомство с переменными и вводом
- `quiz.py` — викторина: условия, циклы, структуры данных
- `lists.py` — задачи на списки
- `shop.py` — расчёт стоимости товаров: список словарей
- `make_data.py` — генератор продаж магазина в формате csv
- `analysis.py` — анализ продаж магазина

## analysis.py — анализ продаж

Программа читает `orders.csv` (200 заказов) и считает выручку,
скидки, разбивку по категориям, товарам и дням недели.

### Выводы

- Скидки снижают выручку на 7.1% — это 162 754 руб. за период.
- Комнатные растения дают 64.5% выручки при 30% заказов.
  Причина — они дороже: средняя цена 958 руб. против 178 руб.
  у срезанных цветов.
- Худший результат у срезанных цветов — 12.8% выручки.
- Скрипт `make_data.py` генерирует данные случайно, поэтому разбивка
  по дням недели — шум, устойчивых закономерностей в ней нет.

## Как запустить

```bash
python quiz.py
```

Нужен Python 3.10 или новее.
